# HttpsAgent Scoop Bucket

[Scoop](https://scoop.sh) manifest for [HttpsAgent](https://github.com/httpsagent/httpsagent) on Windows.

```powershell
scoop bucket add httpsagent https://github.com/httpsagent/scoop-bucket
scoop install httpsagent
```

Update with `scoop update httpsagent`, remove with `scoop uninstall httpsagent`.

The manifest is generated by each release; please open issues in [httpsagent/httpsagent](https://github.com/httpsagent/httpsagent/issues).
